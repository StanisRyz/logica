- **Запуск Catalog не вынесен.**
  - Скелет общий: разрешение уровня → `Unavailable` → загрузка → `isCurrent` → определение → движок → `Playing`, ошибка → `Error`.
  - Но у каждой игры свой запечатанный тип состояния и свой путь загрузки и построения, так что помощнику понадобились бы 4–5 лямбд на вызов.
  - Оценка — около 100–130 строк чистыми ценой обобщённого кода над семью типами состояний. Это ниже порога и ближе к «фреймворку», чем к помощнику.

### 4. Кэш текста подсказок Nonogram

- **Как было.** `drawClue` на каждой перерисовке вызывает `measurer.measure`, цвет входит в стиль. `rememberTextMeasurer()` по умолчанию кэширует 8 раскладок.
- **Как мерил.** Временная сборка: production Wasm, Chromium, 12×12 Expert, уровень 1. 200 вызовов `drawBoard` подряд в одном кадре, время через `TimeSource.Monotonic`.

| Вариант | 200 перерисовок | На одну |
|---|---|---|
| Как есть | 279–359 мс | 1.4–1.8 мс |
| Кэш по (текст, размер), цвет при рисовании (`drawText(color = …)`), `cacheSize = 48` | 274–310 мс | 1.4–1.6 мс |
| Без подсказок совсем | 46–51 мс | 0.25 мс |
| Только измерение без рисования текста, как есть | 109–126 мс | ~0.6 мс |
| Только измерение без рисования текста, с кэшем | 105–129 мс | ~0.6 мс |

- **Вывод.** Измерение занимает ~0.3 мс на перерисовку, и `TextMeasurer` его уже кэширует: с кэшем и без него разницы нет. Основное время уходит на отрисовку самого текста.
- **Перерисовка редкая.** Поле перерисовывается только при изменении состояния (касание, подсказка), а не каждый кадр.
- **Итог.** Выигрыш не подтвердился, правка откачена, код не менялся.

### 5. Мёртвая ветка `CrownsHintProvider`

- **Ветка действительно недостижима.** Единственный вызов из игры (`CrownsGameEngine.logicalHint`) передаёт пустой набор меток, поэтому `INCORRECT_MARK` не возникает.
- **Удалено:**
  - значение `CrownsHintKind.INCORRECT_MARK` и действие `CrownsHintAction.CLEAR_MARK` — других использований нет ни в одном модуле, `when` по ним нет;
  - `findIncorrectMark`;
  - перегрузка `hint(puzzle, state, userMarks)` и исключение меток из кандидатов — без проверки «метка на короне решения» эта перегрузка дала бы логике неверные исключения;
  - строки `crowns_hint_incorrect_mark` на трёх языках — их никто не читал.
- **Нигде не сохраняется.** Подсказка — значение в памяти, в сохранения она не попадает.
