# Этап 10.3. Word на английском и турецком в игре; заморозка паков V3/V4

Перед работой прочитай `AGENTS.md` и `tasksandreports/README.md`, а также отчёты 10.1 и 10.1a. Работа идёт прямо в `main`.

**Владелец одобрил заморозку.** Ответы на вопросы 10.1a:
- KeNet не подключаем, ручной список остаётся;
- военные слова и сказочные персонажи в ответах остаются;
- слова, убранные фильтром по первому значению, не возвращаем.

Словари V3/V4 в нынешнем виде (коммит `d3cc9d3`) — окончательные.

## Архитектура (решено в 10.1, не пересматривать без причины)

- **Игра одна** — `PuzzleType.WORD`. Язык слов = язык интерфейса:
  - русский: ru/be/kk/uk/uz → V2;
  - турецкий: tr → V4;
  - остальные → английский V3.
  - Android берёт язык из `AppLanguage`, Web — из `WebAppLanguage`.
- **Прогресс уровней общий для языков.** Номер уровня Word один, строка прогресса `WORD + сложность + пак V1` не меняется. Звёзды, статистика и рейтинг `ratingWord` тоже общие.
- **Содержимое уровня N берётся из бакета своего языка.**
- **Room, ключи прогресса и форматы сохранений не меняются.**

## Что сделать

### 1. Паки (заморозка)

- **Новые бакеты в паке V1** — так же, как в своё время добавлялись Nonogram и Блок-судоку: `levels/v1/word_en/<difficulty>.lvp` и `levels/v1/word_tr/<difficulty>.lvp` (или другой сегмент пути — обоснуй). Генератор V3/V4, скан сидов по тому же правилу, что у русского V2: «каждый ответ до повтора».
- **Заморозка.** Через `buildCatalogLevelPacks` с флагом создания, который пишет только недостающие бакеты. Контрольные суммы добавляются в `checksums.sha256`.
- **Все существующие бакеты** проверяются как есть: `verifyCatalogLevelPacks` без изменений хешей.
- **Чтение.** Определение уровня по языку: `CatalogLevelPacks` / определение уровня Word выбирает бакет по языку. Идентичность уровня (`CatalogLevelId`) и прогресс язык не содержат; язык виден из версии генератора на результате.
- **Веб** грузит только бакет и словарь своего языка, лениво.

### 2. Интерфейс

- **Название игры:** «Слова» / «Words» / «Kelime». Убери `WordLanguageNotice` и упоминания «только русский» в названиях, правилах, обучении и на экране сложности. Правила говорят о языке слов игрока («Угадайте слово…» / «Guess the English word…» / «Türkçe kelimeyi tahmin et…»).
- **Клавиатуры** (`WordKeyboard`):
  - **EN:** QWERTY 10/9/7, Enter и Backspace по краям третьего ряда;
  - **TR:** турецкая Q без q/w/x — `e r t y u ı o p ğ ü` / `a s d f g h j k l ş i` / `z c v b n m ö ç`, Enter и Backspace по краям третьего ряда;
  - **RU:** без изменений.
  - **Ширина буквенной клавиши** = ширина самого широкого ряда / его длина. Обобщи нынешнее правило 12/11/9, русская раскладка должна выглядеть как прежде. Бюджет высоты без прокрутки — как в `AGENTS.md`.
  - **Ландшафтная панель** — ряды по пять, как сейчас, на всех языках.
- **Ввод с физической клавиатуры на вебе** (`WebKeyboard`/`GameKey`): буквы своего языка — набранные символы через нормализатор языка плюс физические позиции раскладки (EN QWERTY, TR Q). Турецкое `i`/`İ`/`ı`/`I` — через `TurkishWordNormalizer`.
- **Буквы.** Рисуются шрифтом Rubik: турецкие ğ ı İ ş ç ö ü уже в подмножестве — проверь `FontSubsetCoverageTest`. Верхний регистр для показа: турецкий `i → İ`, `ı → I` по своей таблице, не через локаль платформы.
- **Карточка результата и ответ** («Слово было: …») — на языке игры. Шеринг Daily не затронут: Word не входит в V8.

### 3. Daily и старые прогоны

- **V8 без Word.** Существующие прогоны V7 с Word остаются русскими (версия V2 в их определении), как и сейчас. Это ожидаемо, опиши в отчёте.

### 4. Тесты

- Выбор версии по языку на обеих платформах.
- Определение уровня N для каждого языка берётся из своего бакета; прогресс общий: решение уровня 3 на английском двигает тот же прогресс.
- Раскладки клавиатур: состав букв и что каждая буква алфавита есть ровно один раз.
- Ввод `İ`/`I` в турецкой игре.
- `verifyCatalogLevelPacks`: старые хеши не изменились, новые записаны.
- Golden V3/V4 не меняются.
