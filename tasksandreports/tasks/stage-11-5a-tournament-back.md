# Этап 11.5a. Турнир недели: «назад» ведёт туда, откуда открыли

Перед работой прочитай `AGENTS.md` и `tasksandreports/README.md`. Работа идёт прямо в `main`. Только веб.

Просьба владельца: сейчас строка турнира на Game Hub открывает страницу турнира через вкладку Профиля (`WebReadyContent.kt`: `pendingProfilePage = ProfilePage.TOURNAMENT; route = WebRoute.Profile`), и «назад» ведёт в Профиль. Нужно так:

- **Открыли из Профиля** (строка «Турнир недели») → «назад» возвращает в Профиль, как сейчас. Подпись «К профилю».
- **Открыли с Game Hub** (строка турнира под Daily) → «назад» возвращает на Game Hub, на ту же прокрутку, если это просто. Подпись «К играм» (`web_to_games` или существующая строка «К играм» / «To games» / «Oyunlara»).
  - Пока страница открыта с хаба, в навигации (нижняя панель / рельс) выбрана вкладка «Игры», а не «Профиль».
- Esc и браузерное «назад» (если они обрабатываются для этой страницы) ведут туда же, что и стрелка.
- **То же правило — для архива Daily.** Его тоже открывают из двух мест: кнопка «Архив» на хабе и тап по дню в календаре Профиля (`onOpenDailyDay`). Проверь, куда сейчас возвращает «назад» из архива, открытого из календаря. Если не в календарь Профиля — сделай так же: откуда открыли, туда и вернуть, с подходящей подписью.
- Источник открытия — простое состояние хоста рядом с маршрутом. Его не сохранять и не синхронизировать. Смена игрока сбрасывает маршрут на хаб, как сейчас.
