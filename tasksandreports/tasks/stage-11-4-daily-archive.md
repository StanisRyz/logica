# Этап 11.4. Архив Daily

Перед работой прочитай `AGENTS.md` и `tasksandreports/README.md`. Работа идёт прямо в `main`. Сначала проверь, что 11.3 (сохранение серии) уже в `main`: оба задания трогают Daily и запись наград.

Решение владельца: игрок может сыграть Daily прошлых дней.

## Правило (решение архитектора; числа временные)

- **Глубина:** последние **30 дней** до сегодняшнего (без сегодня).
- **Открытие дня:** **5 гемов** или **1 rewarded-реклама** за день. Открытый день остаётся открытым навсегда, все его задачи играются сколько угодно.
  - Числа в `EconomyPolicy`: `DAILY_ARCHIVE_DAYS = 30`, `DAILY_ARCHIVE_UNLOCK_GEMS = 5`.
  - День, где игрок в свой день уже начинал прогон (есть запись прогона или результат), открывается **бесплатно**: он уже «его».
- **Состав дня.**
  - Есть сохранённый прогон — по его `policyVersion`, как всегда: старый V7 с Word остаётся V7, Word русский.
  - Прогона нет — новый прогон с `NEW_RUN_VERSION` (V8) на ту дату. Определения детерминированы по дате, без случайного сида.
- **Игра — как обычный Daily:**
  - жизни: 0 жизней блокирует, `FAILED` стоит жизнь, выход с прогрессом — тоже;
  - второй шанс, правила 2048 Daily, интерстишиалы при выходе;
  - статистика записывает попытки, как обычно.
- **Засчитывание:**
  - Решённые задачи архива заполняют день в календаре. Полный день увеличивает «полные Daily».
  - **Серию архив не засчитывает:** день засчитывается в серию только решениями, сделанными в сам этот день. Восстановление серии — только через 11.3.
  - Квест «реши задачи дня» считает только сегодняшний Daily. Квесты «сыграй/реши в игре …» считают архивные попытки как любые.
- **Шеринг** — только сегодняшний Daily, как сейчас.

## Хранение (разрешено этим заданием)

- **Android.** Room-схема не меняется.
  - Открытие дня — строка журнала `daily_archive:<date>` (−5 гемов или 0 за рекламу).
  - Прогон и результаты — обычные `daily_runs` / `daily_challenges` / `game_results` прошлой даты.
  - **Серия:** Daily-результат даты D засчитывает серию, только если он сохранён до открытия архива для D. То есть у D нет строки `daily_archive:<D>`, или результат записан раньше её `created_at`.
    - Старые результаты не теряют засчитывания: архива раньше не было.
    - Проверь путь агрегации серии (`StatisticsRepository` / Today) и покрой тестом.
- **Веб.**
  - Открытые дни — множество в Player-scoped записи наград (новая версия `LGDR` поверх 11.3, слияние объединением).
  - Daily-история получает новую версию снимка с маской **«решено в свой день»** (`onTimeSolvedMask`), слияние побитовым ИЛИ. При чтении старой версии она равна `solvedMask`: все старые решения сделаны в свой день.
  - Серия на вебе засчитывает дату по `onTimeSolvedMask` (V5+: любая задача), полнота дня — по `solvedMask`, как сейчас.
  - Запуск архивной задачи — через тот же `WebDailyGameplayCoordinator` с явной датой. Токены и смена игрока работают как сейчас.
  - Дата «сегодня» по-прежнему из `WebClock`.

## Интерфейс (общая презентация в `:shared-ui`)

- **Вход.** Кнопка «Архив» в разделе Daily на Game Hub. Также тап по прошлому дню в календаре профиля открывает этот день в архиве, если он в пределах 30 дней.
- **Экран/лист архива:**
  - список дней, новые сверху: дата (уже отформатированная хостом), прогресс `k/n`, замок у неоткрытых;
  - тап открывает день — те же карточки задач, что в разделе Daily (`DailyEntryCard`), с датой в заголовке;
  - открытие — «5 [гем]» и «Смотреть рекламу» с подписью «за рекламу»;
  - карточка результата архивной задачи — заголовок с датой дня.
- **Веб:** в ландшафте ≥ 720 dp — читаемая ширина.
- Тексты на трёх языках, `<plurals>`.

## Тесты

- Ядро/общие: выбор политики для дня с прогоном и без; окно 30 дней.
- Android: открытие идемпотентно; бесплатное открытие уже начатого дня; архивное решение не засчитывает серию, но заполняет календарь и «полные Daily»; старые результаты засчитывают, как раньше.
- Веб: кодек нового снимка Daily и чтение старого (`onTimeSolvedMask = solvedMask`); слияние; серия по `onTimeSolvedMask`; смена игрока во время архивной попытки.
