# Этап 11.6. Финальная проверка перед отправкой в Яндекс Игры

Перед работой прочитай `AGENTS.md`, `tasksandreports/README.md` и отчёты 11.1–11.5. Работа идёт прямо в `main`.

Это последняя проверка перед модерацией. Требования — https://yandex.ru/dev/games/doc/ru/concepts/requirements. Пройди **все** разделы требований заново, а не только список 11.1: после 11.2–11.5 появились новые кнопки рекламы, покупки за гемы и таблицы.

## 1. Сборка

- Собери `./gradlew :web-app:packageYandexDistribution`. Запиши:
  - имя и размер архива;
  - размер в распакованном виде (< 100 МБ);
  - SHA-256;
  - число файлов.
- Проверь архив:
  - `index.html` в корне;
  - нет пробелов и кириллицы в именах файлов;
  - нет `.map`, тестовых и лишних файлов;
  - `<script src="/sdk.js">` на месте;
  - нет абсолютных `https://` к ресурсам игры (1.7);
  - нет упоминаний RuStore, Google Play, Android-ссылок и внешних адресов в коде, который видит игрок (8.4).

## 2. Проход по требованиям

Таблица в отчёте: **пункт → как проверено → результат → что исправлено**. Обязательно:

- **1.x — техника.**
  - Загрузка: `LoadingAPI.ready` после первого кадра.
  - `GameplayAPI.start/stop`; пауза и возобновление (1.19).
  - Звук не играет в фоне и во время рекламы.
  - Без долгого нажатия и контекстного меню (1.6), ≤ 2:1 на ПК.
  - Нет обрезанного и полосы прокрутки на 360×640, 390×844, 412×915, 1366×768, 1920×1080 (1.10).
  - Старый браузер — JS-сборка (1.20).
  - Облачные сохранения работают при отказе облака.
  - Покупки (1.13): `getPurchases` и `consumePurchase`; список id в коде совпадает со списком для консоли.
- **2.x — интерфейс:**
  - язык выбирается автоматически по `i18n.lang`;
  - все тексты на трёх языках, без пропусков ключей;
  - нигде нет «Логика» / «Logica»;
  - нет непереведённых строк.
  - Скрипт: сравни ключи `values`, `values-en`, `values-tr` во всех модулях.
- **3.x — контент:** без религиозной и политической символики, насилия и реальных призов (3.7). Гемы и недельные призы — внутриигровые; так и описать.
- **4.x — реклама:**
  - каждая rewarded-кнопка подписана «за рекламу» и говорит, что даёт, на трёх языках. Новые кнопки из 11.3 и 11.4 тоже;
  - интерстишиалы только при выходе из игры, не чаще 90 с и не в первые 2 мин;
  - баннер не закрывает игру;
  - после «Без рекламы» нет ни интерстишиалов, ни баннера.
- **5.x — промо:** название в игре совпадает с промо на каждом языке: «Головоломки» / «Puzzles» / «Bulmacalar».
- **8.x — ссылки и данные:** нет внешних ссылок; нет сбора персональных данных вне SDK.

## 3. Дымовой прогон в Chromium (Playwright, standalone)

На трёх языках (`?lang=ru|en|tr`), светлая и тёмная тема, 390×844 и 1366×768:
- Game Hub → каждая из семи игр (экран сложности и первый уровень Лёгкий);
- Daily, архив Daily, Профиль (все страницы), Магазин, настройки, «Лицензии», турнир недели (через подставной мост, если standalone его скрывает).

Требования:
- консоль без ошибок;
- без пустых строк (ресурсы загрузились);
- без обрезанного текста.

Скриншоты — в `tasksandreports/reports/img/stage-11-6/`, сводным листом на язык, не по одному файлу на экран.

## 4. Тексты для консоли

Файл `tasksandreports/reports/yandex-console-texts.md`, для каждого из RU / EN / TR:
- название;
- короткое описание (до 100 символов);
- «Об игре»: семь игр, Daily, турнир недели, без внешних ссылок и упоминаний других платформ;
- «Как играть»;
- ключевые слова/теги.

Отдельный раздел **«Что владелец делает в консоли»**:
- покупки: `gems_50`, `gems_150`, `gems_500`, `starter_pack`, `no_ads` — id, тип, что даёт;
- таблицы: восемь существующих плюс `weeklyStarsA`, `weeklyStarsB` — имена и настройки;
- облачные сохранения;
- реклама (rewarded, interstitial, sticky-баннер);
- возрастной рейтинг;
- категории;
- что нужно от владельца из графики: иконка 512×512, обложка 800×470, скриншоты — можно взять из п. 3.
