# Логика дня

Minimal native Android baseline for the future "Логика дня" application. Built with Kotlin, Jetpack Compose, Material 3, and Gradle Kotlin DSL.

Requires JDK 17 and Android SDK Platform 36.

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
